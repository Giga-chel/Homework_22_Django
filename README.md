# Skystore

**Skystore** — это веб-приложение на базе Django, представляющее собой каталог для продажи плагинов, примеров кода, веб-приложений и утилит. Проект включает в себя главную страницу с продуктом и страницу контактов с формой обратной связи.

## Стек технологий

- **Python 3.x**
- **Django 6.0** (указано в настройках проекта)
- **HTML5 / CSS3**
- **Bootstrap 5.3** (подключается через CDN)
- **SQLite** (база данных по умолчанию)

## Структура проекта

- `config/` — корневая директория проекта (настройки, URL).
- `catalog/` — основное приложение, содержащее логику отображения страниц.
- `catalog/templates/` — HTML шаблоны для страниц.

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone < https://github.com/Giga-chel/Homework_22_Django.git >
cd < папка проекта >
```

### 2. Создание виртуального окружения (рекомендуется)
**Для Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**Для macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
Убедитесь, что находитесь в корневой директории проекта, где лежит файл `requirements.txt`:
```bash
pip install -r requirements.txt
```

### 4. Применение миграций базы данных
```bash
python manage.py migrate
```

### 5. Запуск сервера
```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Функционал

- **Главная страница (`/`)**: Отображает название магазина, краткое описание и карточку товара с ценой и характеристиками.
- **Страница контактов (`/contacts/`)**: Содержит информацию о компании и форму обратной связи. При отправке формы данные обрабатываются представлением (с выводом в консоль).

## Контакты разработчиков

Информация для связи указана на странице `/contacts/` в самом приложении.
