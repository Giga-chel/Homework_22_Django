# Django Catalog Project
    
Этот проект создан в рамках учебного задания.
    
## Стек технологий
- Python
- Django
- Bootstrap 5
    
## Запуск проекта
1. Активируйте виртуальное окружение.
2. Установите зависимости: `pip install -r requirements.txt` (если создали файл)
3. Выполните миграции: `python manage.py migrate`
4. Запустите сервер: `python manage.py runserver`
